                           AI RESEARCH COPILOT
                 Full-Stack Implementation Plan & Architecture
================================================================================

1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
AI Research Copilot is an intelligent, full-stack research assistant designed
to help researchers ingest, read, analyze, compare, and synthesize academic
papers with grounded, citation-backed AI assistance using Flask, Gemini API,
ChromaDB, and modern frontend web technologies.


2. TECHNOLOGY STACK
--------------------------------------------------------------------------------
Backend:
  - Python 3.10+
  - Flask (REST API, application factory, blueprints)
  - Flask-CORS (Cross-Origin Resource Sharing support)
  - PyMuPDF (fitz) (High-speed PDF text, layout, and page extraction)
  - Google GenAI SDK (`google-genai` with Gemini 2.5 Flash)
  - ChromaDB (Local vector database for chunk indexing & RAG retrieval)
  - Requests (arXiv API search & automated PDF downloading)
  - Pydantic & python-dotenv (Data validation & environment configuration)

Frontend:
  - Responsive Single-Page Application served via Flask templates & static assets
  - Tailwind CSS & modern UI styling (dark/light clean academic theme)
  - Lucide Icons
  - PDF.js (In-browser split-view PDF reader with page-jump synchronization)
  - Marked.js + Highlight.js (Markdown & code snippet rendering)
  - KaTeX (LaTeX mathematical formula rendering)
  - Server-Sent Events (SSE) (Real-time streaming AI answers)


3. SYSTEM ARCHITECTURE & FLOW
--------------------------------------------------------------------------------
[User Browser / Frontend]
   |
   +--> Dashboard & Library: Search, upload PDFs, or query arXiv
   +--> Split-Screen Reader: Left pane (PDF.js viewer), Right pane (AI Copilot Chat)
   +--> Literature Matrix: Multi-paper comparative analysis table
   |
[Flask REST API & Routes]
   |
   +--> /api/papers (Upload PDF / Fetch from arXiv / Get Metadata)
   +--> /api/chat   (RAG pipeline query & SSE streaming response)
   +--> /api/synthesize (Multi-document comparative matrix generation)
   |
[Processing & Ingestion Pipeline]
   |
   +--> PyMuPDF: Extracts text, sections (Abstract, Intro, Methods, Results, etc.)
   +--> Recursive Chunker: Splits sections into context chunks with page numbers
   +--> ChromaDB: Indexes embeddings for semantic similarity search
   |
[AI & Reasoning Engine]
   |
   +--> Google Gemini 2.5 Flash: Grounded responses with strict citations [p. X]
   +--> Synthesis Agent: Generates structured comparison JSON (methods, datasets, metrics)

6. QUICK START COMMANDS
--------------------------------------------------------------------------------
1. Activate Virtual Environment:
   .\venv\Scripts\Activate.ps1

2. Install Dependencies:
   pip install -r requirements.txt

3. Set up Environment Variables:
   Copy-Item .env.example .env
   # Edit .env and insert your GEMINI_API_KEY

4. Run the Development Server:
   python run.py

5. Access the Web Application:
   http://127.0.0.1:5000
